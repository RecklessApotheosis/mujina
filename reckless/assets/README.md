# reckless.rgb565

The Reckless Systems logo for the Nano 3S panel: 240x240, RGB565 little-endian,
115,200 bytes, the same raw format as the pizza page's image. It is installed
on the device as `/data/reckless.rgb565` and shown on the `reckless` page.

Source: `reckless-systems-logo-on-dark.svg`
(sha256 af44dede0b9b1bc2b9ae799e91a622499c50c3000976b6466c6e16f202fc34a9),
rendered on black at 164x189 px, centred (Ronald, 2026-11-11: 10% larger
than the first 149x172 render). Its farthest pixel is 94.8 px from the
centre, inside the panel's 120 px radius.
